# Attribution

This is a new, independent implementation of the display architecture used in the private Master App business-document helpers: a shared document shell, escaped fields, document metadata, grouped rows, customer-facing totals and a separate filename helper. The source architecture was developed for a private business application; this standalone implementation was authored with AI assistance.

The implementation deliberately changes the public boundary to plain customer-facing DTOs and exact decimal-string arithmetic. No original application source file is bundled. The original application, database, cost/markup calculation, authentication, business clauses, artwork, fonts, customer records, prices, contacts and branding are excluded.
